Changes

  • Pins. contracts.json gains one pin per reviewer slot: eight slots by provider, tier and read scope, plus the staffing recommender and the trend checkpoint. OpenRouter reads a whole document at low and a diff at high. Codex frontier slots run at high, mid slots at medium. No pin names a model. The routing table does that.
  • Tool grants. Every grant is the Codex read-only sandbox, or a list drawn from Read, Grep and Glob. No reviewer gets a shell pattern, because git diff --output=<path> writes a file.
  • The change as a file. The emitter writes <reviewer>.diff beside each prompt, over that reviewer's scope for the round. Reviewers sharing a revision pair share one computed diff.
  • Round record. Each reviewer entry gains effort and tools copied from its pin. A slot with no pin refuses the round and writes nothing.
  • Rosters. Each artifact class keeps exactly one OpenRouter reviewer. Four reviewers move to Codex. Declared tiers do not change.
  • Recovery sequence, in the gate. dispatch_gate.py claim takes --effort and records it. A run that died may be claimed again only as the same model one effort step lower, or as the other provider at the same tier and scope. Anything else is refused and costs no attempt. Three attempts, then the round halts with guidance.
  • Doctrine. harvest.md states the sequence, the failover slot, the diff file and the claim form. Nine scenarios with expected answers check that a reader holding only those files reaches the right dispatch.
Design notes

The earlier design routed the OpenRouter mid-tier model away from whole-document reads. That constraint had no run record behind it, and the only recorded reads of that shape on that model had finished. A constraint stated without its variables cannot be scoped or falsified, so the design no longer encodes it. A slot that names a model runs that model. The recovery sequence answers for a death when one happens, and records every attempt.

Rejected: letting the dispatcher pick a fallback model freely. That hides the cost decision in a prompt and leaves no record. Rejected: a shell grant restricted by a command prefix. Both git diff and git log accept --output, so a prefix pattern is not read-only.
