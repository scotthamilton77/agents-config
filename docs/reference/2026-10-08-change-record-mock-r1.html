Until now the agent running a review round chose each reviewer's effort level and tool grant itself, and routed some models away from whole-document reads on a belief that had no run record behind it. feat(9k9.315.14): on the grilling board, any answer typed in the human's own words now goes to the expert seat

#838 · merged · +281 / −83 · production diff +50 / −14 across 4 files
Was: feat(9k9.315.14): every answer in the human's own words is weighed by the expert, whether or not it opens anything

The grilling board has two seats that compose replies: a fast first rung and a slower expert. Before this change, a typed answer went to the expert only when it opened or changed a decision. Now any answer carrying a note or free text goes to the expert, whether or not anything is downstream of it. If nothing is, no impact task is recorded and nothing waits. This completes slice S2 of the pending-analysis spec by following its decision PND-D4 as written, and builds on #829, which is merged.

Where this fits

agents-config-9k9 Harness rework (milestone) └ agents-config-9k9.315 grilling board: pending analysis, impact tasks, terminal review (spec) └ agents-config-9k9.315.14 this change, the last of slice S2

Risk

  • If this is wrong: a typed answer is weighed at the wrong effort, so the human either waits on the heavy seat for a trivial note or gets a shallow read on a channel they deliberately moved to the expert. The board's map-side prose escalation conditions become unreachable, which is intended, but the code for them is still present.
  • Mitigation: five new unit tests pin the three-way effort rule; thirteen existing tests were moved or re-pointed with their assertions unchanged; the browser suite passes at 97.
