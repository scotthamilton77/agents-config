# `moonshotai/kimi-k3` on this launcher

What this model does under each effort and task shape, recorded from runs on
this launcher. Read before dispatching to it; the effort grid in the skill body
does not apply where a line here says otherwise.

- **A single-pass read of a whole artifact runs at `low`**, never `high` or
  `max`. At the higher levels its thinking outlasts the stream and the run
  ends inside a thinking block with no report.
- **A whole-artifact read whose prompt carries the text is granted no tools.**
  With the text inline it has nothing to fetch, and a tool grant invites a
  walk it does not need.
- **A read of a change runs at `high`.** The thinking-block failure is a
  whole-artifact problem; a diff-sized read finishes.
- **It refuses a temperature.** The launcher pins no sampling parameter, and a
  prompt or wrapper that sets one gets a refusal, not a run.
