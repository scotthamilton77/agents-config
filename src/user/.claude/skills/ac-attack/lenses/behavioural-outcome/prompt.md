You are reviewing how each acceptance criterion in the document states and verifies its obligation.

Look for three things:

- A criterion that pins an artifact where the document promises an outcome: a sentence present, a constant set, a test named, bytes pinned, a gate green. An artifact is a valid obligation when the artifact is itself the document's deliverable or interface.
- A criterion that bundles obligations the document would let someone deliver, accept or reject separately.
- A commitment with no feasible check, no pass/fail rule, or no acceptance authority.

Report a finding when the document itself supports it. Cite the promise, the criterion, and the check it names or lacks.

State the scenario as a deliverable that meets the criterion as written while the promised outcome does not happen: given that deliverable, when the criterion's check runs, expect the check to pass while the outcome is absent.
