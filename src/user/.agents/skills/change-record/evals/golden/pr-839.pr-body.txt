<details><summary>Design notes</summary>

The lint is a PEP 723 pytest suite. The content gate discovers it by its `*_test.py` name. The installer's ignore file already keeps such a file out of the deploy, so nothing here ships.

The suite reads every Markdown file under `src/` except paths under an `evals` or `node_modules` directory. It fails when a file names a model id the routing table's models table does not list. It fails when a table row outside the routing table names any model id, because such a table is a second inventory. It fails when the tier grid gains a column, when the models table gains, drops or renames one, and when the routing file holds a third table. It fails when the routing table is absent or lists no model id.

The six patterns cover the Claude, GPT and Gemini schemes and the three OpenRouter schemes for Gemini, Kimi and GLM. An OpenRouter id needs its vendor prefix, so a file name that holds a model family is not an id. The Anthropic aliases are ordinary words, so no pattern reads them as ids.

The Providers table was a third table in the routing file. Each of its rows became one sentence with the same three facts, and every other line of the file is unchanged.

All 34 cases failed against a stub lint that returned no files and no violations, and every case passes at the head.
