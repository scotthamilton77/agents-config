spec(change-record): one linted record behind the PR body, commit message and review reply [9k9.484]

Work item agents-config-9k9.484, the change-record spec.

Why
Agents write pull request descriptions, commit messages and review
replies with no template. The owner has to re-read or ask before
approving, because ids go unexplained and no description places the
change or lists its risk.

Change
The spec decides the three templates and a JSON change record as their
single source. The record lives in a marked, append-only pull request
comment, and a merge command supplies the commit message from it. A
bounded rewrite pass on a second model proposes prose that the author
accepts or prunes. Seven slices carry 69 criteria, and the squash
setting flips last.
